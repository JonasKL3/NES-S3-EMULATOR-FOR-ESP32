# Controles — Dabble GamePad

| Ação | Menu | Durante o jogo |
|---|---|---|
| D-pad ↑ ↓ | Selecionar jogo | D-pad NES |
| D-pad ← → | Alternar Todos/Favoritos/Recentes | D-pad NES |
| Analógico | Seleção e direção quando disponível | Direção com prioridade para D-pad digital |
| X (Cross) | Abrir jogo / confirmar | NES A |
| □ (Square) | Favoritos / apagar no teclado | NES B |
| △ (Triangle) | Busca | NES B |
| ○ (Circle) | Cancelar/limpar busca | NES A |
| START | Confirmar continuar | START NES |
| SELECT | — | SELECT NES |
| START+SELECT mantidos 700 ms | — | Abrir menu de pausa |

No menu de pausa, opções de continuar, configurar vídeo/áudio, saves e sair. Voltar do jogo não exige `ESP.restart()`.
