# Créditos

- **NES-S3**: integração para ESP32-S3, interface, gerenciador local, cache ROM e integração de hardware do projeto.
- **Nofrendo**: núcleo NES de terceiros, usado por meio da biblioteca externa [moononournation/arduino-nofrendo](https://github.com/moononournation/arduino-nofrendo), com patches locais não redistribuídos.
- **ESP32-NESEMU / Espressif**: referência arquitetural para o port NES em ESP32: https://github.com/espressif/esp32-nesemu.
- **TFT_eSPI / Bodmer**: biblioteca de display externa: https://github.com/Bodmer/TFT_eSPI.
- **DabbleESP32 / STEMpedia**: biblioteca externa do gamepad BLE: https://github.com/STEMpedia/DabbleESP32.
- **Anemoia / Shim06**: inspiração da paleta NES em `halo_fixed_palette.h` (arquivo preserva crédito e aviso de GPL-3.0).
- **Retro-Go / ducalex**: referência comparativa de organização e arquitetura; não foi copiado código deste projeto: https://github.com/ducalex/retro-go.

Respeite as atribuições e as licenças originais. Esta lista não transfere a autoria de terceiros ao projeto NES-S3.
